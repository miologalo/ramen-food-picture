# Make the best-looking food picture

Entry for make.fun's **"Make the best-looking food picture"**
(food-picture-01).

`main.py` (Python 3.13, stdlib only) writes one image to
`/output/entry.png`: a steaming bowl of ramen, shot overhead in warm
light — chopsticks lifting glossy noodles from a rich golden broth, a
halved soft egg with a runny yolk, charred pork, chili oil swirls, green
onions and nori on a rustic wooden table.

The image is original art made for this entry (`image.jpg`, bundled here).
JPEG, 1024x683, 225,510 bytes (within the 1 MiB and 1024x1024 limits).

## Run locally

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
