# Make the best-looking food picture

Entry for make.fun's **"Make the best-looking food picture"**
(food-picture-01).

`main.py` (Python 3.13, stdlib only) writes one image to
`/output/entry.png`: an extreme close-up of a gourmet burger, filling the
frame — a glossy toasted bun, melted cheese dripping down a charred patty,
fresh lettuce and tomato, steam rising, dramatic golden-hour light and a
dark moody background that makes the food glow.

The image is original art made for this entry (`image.jpg`, bundled here).
JPEG, 1024x683, 157,532 bytes (within the 1 MiB and 1024x1024 limits).

## Run locally

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
